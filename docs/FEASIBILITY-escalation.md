## 11. 升级门省费（S06 / G26）：**机制成立，但量级对不上**

gallery 标注：τ=0.6 升级门，大模型调用 **−55.0%**（τ=0.5 档 79.6%），
acc 0.906→0.9936 (kept subset)。

前九族测的都是"判定对不对"。这一族测的是**另一件事**：升级门的经济性。它的机制是
"置信度低的才升级给大模型，高的就在本地定"，所以能不能省取决于**置信度能不能把
'本地答对的' 和 '本地答错的' 分开**。这是一个关于**模型自知之明**的测量 —— 即使
模型准确率不高，只要它"知道自己什么时候不确定"，门就能省下调用。

`docs/measure-escalation-savings.mjs`：把前两族已用的语料（路由 8 条 + 中文 8 条）
重跑一遍，取所选选项的概率作为置信度（与 `/v1/systemone` 的 `answer_confidence`
同口径），然后扫描阈值。

### 实测结果

```
overall accuracy: 10/16 = 63%

confidence distribution (所选选项的概率):
  min 0.361  p25 0.418  median 0.491  p75 0.693  max 0.890
  spread: 0.529

mean confidence when correct : 0.583  (n=10)
mean confidence when wrong   : 0.445  (n=6)     ← 差 0.138
```

**置信度确实分得开。** 正确时平均 0.583，错误时 0.445，差 0.138 —— 这是我设的
判据（>0.05）的两倍多。这是十族测量里**第一次**看到一个 gallery 声称的机制成立。

```
=== 阈值扫描（置信度 >= t 就本地定）===
     t   kept   escalated   local accuracy   escalated accuracy
  0.40   14/16       2/16          71%                0%
  0.45   10/16       6/16          80%               33%
  0.50    7/16       9/16          86%               44%
  0.55    5/16      11/16          80%               55%
  0.60    5/16      11/16          80%               55%
  0.65    4/16      12/16         100%               50%
  0.70    3/16      13/16         100%               54%
```

**单调性是对的**：t 越高，本地子集越准（63% → 71% → 80% → 86%），同时升级越多。
这正是升级门应有的形状 —— 前面九族里从没出现过。

### 但与标注的量级对不上

| | gallery 标注 | 本测量 |
|---|---|---|
| τ=0.6 省下的调用 | **55.0%** | 升级 68.8%（只省 31%） |
| τ=0.5 档 | 79.6% | 升级 56%（省 44%） |
| 本地/kept 子集准确率 | **0.9936** | 80%（τ=0.6）· 86%（τ=0.5） |

**机制成立，幅度只有声称的一半左右，而 kept 子集准确率远低于 0.9936。**
注意我的样本只有 16 条，升级率与准确率的抽样误差都不小；能说的是"方向对、量级
不到"，不能给出替代数字（与 S23 同一个理由）。

### 一个必须说清的附带发现

置信度分得开，**不代表模型判得对**。这 16 条的总体准确率是 63%，而各条置信度
挤在 0.36–0.89、中位数 0.491 —— 也就是说大多数判定的置信度在"微弱多数"附近。

这带来一个实际后果：**升级门省下的是"大模型调用"，代价是本地的错判留在本地**。
在 τ=0.6 下，本地保留的 5 条里有 1 条是错的（80%）；τ=0.65 下保留 4 条全对，但
升级了 12/16。所以这个门**可以用，但要按场景选阈值**：宁可多升级就别设高阈值，
想省调用就要接受本地错误率上升。

### 与前面九族的关系

这是唯一一次 gallery 声称的**机制**经得起复现。值得记下它与众不同的原因：
前九族测的是"模型答得对不对"（依赖模型的世界知识），这一族测的是"模型知不知道自己
不确定"（只依赖它的置信度排序）。**前者不达标，后者部分达标。**

所以 G26 那句"token 省费"在我的测量下**方向正确、幅度减半**；而 S06 的
"acc 0.906→0.9936 (kept subset)" 在 16 条样本上复现不出 —— 我测到的 kept 子集
是 80%，而不是 99.4%。
